Fastsonic is still in migration and has not published a release. There are no
installers, Flatpak, Homebrew tap, or AUR package yet. Inherited Fastpotify
artifacts are not Fastsonic builds.

Build the current development version from source by following
[Getting Started](/getting-started/). The first release will add verified
downloads here only after every platform artifact and its checksum exist.
